Exclusions and extraction notes

How it works

Each row groups the same IFC Name + section size + length. Lengths come from IFC properties or length quantities, converted to millimetres. Original section names and length precision are retained.

Scope and limits
  • Reads text STEP .ifc files, including IFC2X3 and IFC4 member data. Compressed IFCZIP files must be extracted first.
  • Default exclusions: cleats, endplates, plates, clamp plates, baseplates, haunches, thermal breaks and sheets. Clear the checkbox before choosing a file to include those named objects when they belong to a beam, column or member class.
  • Does not require Revit or loaded Revit families. Slanted members are included when their section and IFC Length are available.
  • Does not infer lengths from geometry. Missing or invalid lengths, sections or IDs are listed in the extraction report rather than silently counted. A source name of “Unnamed” stays unchanged; blank names become “Unnamed” and are reported.
  • Section lookup: Revit Family:Type names, IFC ObjectType, Description, then associated type name. Check unusual exports where those fields contain descriptions instead of section names.
  • This is a model schedule, with no stock-length optimisation, cutting allowance, waste, fabrication or procurement adjustment.
